# Series and mental-model courses

Read Munger_Models/README.md, course-guidelines.md, mental-models.json, and age-pathways.md for a Munger course. That research is a provisional mapping, not input that bypasses compiler schemas or a completed course.

Connect each objective to a learner action, observable check, explanation, and novel transfer task. Separate direct support, foundation, analogy, and missing concepts. Check exact IDs/evidence against current data.

Inspect transitive hard prerequisites while keeping teaching scope bounded. Flag suspect edges without changing them. Age guides presentation, never proves mastery.

Use CLI series mode for catalog topics. Custom extensions compile one topic per artifact; produce a course index linking independent units with prerequisite decisions and gaps. Do not call research JSON a built course.

Preserve source-authentication limitations. A domain analogy does not prove a psychological or economic claim. Label toy data and test transfer beyond the original story before inferring broader understanding.
